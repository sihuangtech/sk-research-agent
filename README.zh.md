你的科研个人 Agent。

从读懂一篇论文，到编写分析脚本、运行实验、整理研究结果，第二月亮与你在同一个项目里持续协作。它能够阅读和修改真实文件、调用本机工具，并将成果保存在你的项目文件夹中，让讨论接着变成可以检查、复用的工作。

[English](README.md) · [开始使用](#开始使用) · [从源码运行](#从源码运行) · [数据与后台运行](#数据与后台运行)

## 能帮你做什么

- **理解研究项目**：阅读说明、代码和资料，梳理研究目标、现有成果与下一步需要验证的问题。不同项目拥有各自的研究会话，可以重新打开历史对话继续工作。
- **阅读论文与整理文献**：提取带页码的 PDF 文本，检索文献标题、作者、DOI 和来源链接，辅助整理方法、证据与研究线索。
- **分析数据和执行实验**：检查数据，编写或修改脚本，运行本机命令，将分析结果与图表保存到项目中。项目需要的 Python、R、Julia 等环境需另行安装。
- **在执行中协作**：查看流式回答与工具结果，发送中途指导、排队追加任务，或停止当前轮次。耗时命令可以独立运行，查看状态、最近日志并单独取消。
- **检查和修改成果**：在工作台浏览文件、编辑文本与代码、预览 PDF 和图片。回答支持 Markdown、表格与数学公式，文件保存会检查是否已被其他程序修改。
- **保留研究背景**：保存个人偏好与项目记忆，供后续任务读取；记忆可以随时编辑或删除。
- **积累课题进展**：记录研究问题、假设、证据、实验、决策和下一步，跨会话检索相关历史。每轮结束会留下标记为待核验的 Agent 交接记录。
- **检查来源与执行**：为本地来源和产物保存 SHA-256 指纹，核对 PDF 指定页的原文摘录，发现文件变化；分别查看研究笔记与程序记录的工具/后台命令事件，完整记录可导出为 JSON。
- **安排持续研究**：创建定时任务，例如跟进课题的新文献并更新记录。每次执行都会生成研究会话，方便检查过程和结果。

## 开始使用

1. 打开应用，点击“打开项目”，选择已有的研究文件夹。
2. 打开“设置 → 账号与模型”，先选择供应商，再选择其支持的账号登录或 API Key 方式。使用套餐密钥时，选择对应套餐与地区；完成连接后选择模型并测试。
3. 新建研究会话，选择模型，输入任务。按 `⌘ / Ctrl + Enter` 发送。
4. 在右侧的“文件”“研究”“任务”“记忆”“自动化”中检查成果、管理执行和安排后续工作。

“研究”面板可以手动添加记录、关联已有记录与来源、追加修订并保留原记录。点击来源路径打开文件，使用“检查来源”比较当前文件与记录时的指纹；导出包含修订历史和执行事件。Agent 可以通过科研工具保存和检索记录，新一轮对话也会自动读取相关记录与近期进展。研究记录按项目隔离。

你可以从这样的任务开始：

> 阅读项目说明和现有脚本，整理目前已经完成的工作，以及下一步需要验证的问题。

> 检查 data 目录中的 CSV，说明缺失值和异常值情况，编写可复现的分析脚本，将图表保存到 figures 目录，并记录实际运行的命令。

> 阅读这篇 PDF 的方法部分，标注引用页码，整理实验所需的数据、参数和复现步骤。无法从原文确认的内容请单独列出。

助手能够直接修改文件和执行命令。建议先用一个独立项目熟悉工作方式，并为重要资料保留备份。

## 账号与模型

接入入口按供应商归类：OpenAI 下提供 ChatGPT 登录与 API Key；Kimi 下集中展示账号登录、Coding Plan 密钥与 Moonshot API。Coding Plan 是额度与计费方式，不是另一种认证方式。只有一种接入方式的供应商会直接打开配置页。

- **账号登录**：ChatGPT、GitHub Copilot、Kimi Code。通过系统浏览器授权，无需复制其他工具的登录文件；支持多个独立连接、重新登录与退出。
- **Coding Plan**：智谱/Z.AI、Kimi Code、MiniMax、阿里云百炼/Qwen 和 Xiaomi MiMo 的已配置套餐入口。使用对应套餐及地区的专用密钥，不会自动改走普通 API。
- **按量 API**：OpenAI、Anthropic、Google Gemini、DeepSeek、xAI、OpenRouter、Mistral、Groq、Moonshot、百炼、智谱、MiniMax、硅基流动、火山方舟与 MiMo，也可手动填写兼容接口。
- **本地服务**：Ollama、LM Studio 或自定义服务地址。模型服务需要自行启动。

ChatGPT 使用 [OpenAI 面向本地开源应用的订阅授权](https://developers.openai.com/siwc/token-sharing-open-source)，登录后获取该账号可选的模型；实际资格、共享额度和限制以授权页面与 [ChatGPT 用量设置](https://chatgpt.com/settings/usage) 为准，不是无限额度，也不会自动切换到付费 API。不是每个厂商的聊天订阅都允许第三方使用：本版不提供 Claude/Gemini 的订阅登录，不会把它们的 API 配置标为会员额度。

套餐密钥即使名为 API Key，也可能使用套餐额度而非按量计费，必须匹配所选入口。当前产品保守地将订阅和 Coding Plan 连接限定为交互任务；定时任务请选择按量 API 或本地服务。连接测试会消耗少量额度。供应商预设与模型能力来自已安装 SDK/配置，不代表已逐个通过真实付费账号验证。

“通用”中可设置界面语言与新对话的默认连接；“隐私与执行”说明数据流向和本地执行边界。所有账号登录与令牌刷新均直接复用 Pi 内置实现。退出只清除本应用的本地凭据；如需撤销远端授权，请到供应商账号设置中操作。

## 语言

支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、巴西葡萄牙语和俄语。侧栏底部可切换语言，选择保存在本机；首次启动按系统或浏览器语言偏好匹配。

界面、日期、服务提示和托盘菜单会一起切换，不清空输入草稿。新一轮对话和新建自动任务默认使用所选语言，也可以在任务中指定回答语言。已有文件、用户内容与历史回答保持原文。

编辑器内部菜单的语言在首次加载时确定，切换后需要重启应用才能完整更新。当前编辑器官方巴西葡语资源尚无翻译，其内部菜单仍显示英文；应用自身的葡语界面和提示已翻译。

## 数据与后台运行

项目资料和生成的成果保留在你选择的文件夹中。会话、记忆、任务记录与模型配置保存在本机应用数据目录；API 密钥、OAuth 访问/刷新令牌与安装实例标识单独保存在系统钥匙串中，不以明文写入项目或配置数据库。设置中只显示账号标签，不显示令牌。

使用在线模型时，相关提示词、文件内容、记忆与工具结果会发送给你配置的服务商，模型费用由服务商结算。文献检索需要联网；使用本地模型时，不依赖外部信息的任务可以离线完成。当前没有云端账号、多设备同步或团队协作服务。

关闭窗口后，应用仍可在系统托盘中运行。完全退出应用会停止本地执行。停止一轮对话不会自动取消独立提交的命令任务，需要在“任务”面板中单独取消。

自动任务依赖应用运行。电脑休眠、关机或应用完全退出期间不会执行；重新启动后，已到期的计划只补执行一次，不逐次补跑错过的周期。历史会话可以恢复，但已中断的进程和实验不会自动重跑。

## 从源码运行

需要 Node.js 24 或更新版本。桌面开发与打包还需要 Rust 和 [Tauri 平台前置依赖](https://v2.tauri.app/start/prerequisites/)。在项目根目录执行：

```bash
npm ci
npm run desktop:dev
```

构建本机桌面安装包：

```bash
npm run desktop:build
```

安装包输出到 `src-tauri/target/release/bundle/`，自带所需的 Node.js 运行时，使用者无需另外安装 Node.js。研究脚本所需的环境仍由项目自行准备。不同系统和架构需要分别原生构建。当前 macOS 构建使用本机签名，尚未配置公开发行公证与其他平台发布签名。

浏览器开发调试可运行 `npm run dev`，再打开 `http://127.0.0.1:5173`，开发数据保存在 `.research-data/`。这是连接本机服务的开发入口。

## 当前能力边界

- 研究笔记中的科学结论仍需人工核验。引文匹配只检查文字，文件指纹只表示采集时的状态，URL 不会自动下载核验；每份来源文件最多 50 MB。
- 执行记录来自实际工具事件与后台命令状态；文件/编辑工具可采集目标文件指纹，任意 Shell 输出需另行登记。记录不包含完整的 Python/R 环境快照，不是操作系统级防篡改审计，也不自动执行统计审查。
- PDF 读取以文字层为主，尚不包含 OCR；复杂公式、表格和图片需要结合原文核对。
- 文献检索提供出版元数据与来源线索，不能代替阅读全文和验证研究结论。
- 文件和命令以当前用户权限执行，项目文件夹不是操作系统沙箱；目前没有逐条命令审批或容器隔离。
- 当前提供代码编辑与命令任务日志，尚不包含交互式终端、Notebook 内核管理、远程集群执行或完整 IDE 调试功能。
